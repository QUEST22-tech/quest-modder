# 🎮 Universal VR Mod Installer

A standalone WebUSB-powered desktop application wrapper built to instantly connect and inject custom standalone mod payloads directly into your Meta Quest VR headset without any external configuration tools.

## 🚀 Features
* **Zero-Setup Driver Execution:** Taps directly into native WebUSB communication pathways to find your Quest headset instantly.
* **Automated Sync Matrix:** Direct file streams inject configurations to the app directories without browser network blockades.
* **Dark Interface Hub:** Built inside a sleek, dark-themed dashboard container engineered for smooth, distraction-free operation.

## 📁 Staged Mod Loadout
This installer comes fully pre-configured to transfer these specific mods:
* 🦴 **Bonelab Avatars:** `Mulletman2113 WagieFord Avatar Pack` (All core structural pallet asset and bundle maps included).
* ⚔️ **Beat Saber Hooks:** `SongDownloader.qmod` custom download configurators.

## 💻 How to Use the App (Windows Deployment)

1. Head over to the right sidebar panel and download the latest release bundle archive: **`Universal-VR-Modder-Windows.tar.gz`**.
2. Unpack the compressed archive folder using an archive tool (like 7-Zip or WinRAR) onto your desktop directory.
3. Plug your Meta Quest headset into your PC via a USB-C data transfer cable.
4. **Crucial:** Put your headset on for a brief second and ensure you click **"Allow USB Debugging"** on the internal popup screen.
5. Launch the application layout, click the blue **🔌 Connect VR Headset** dashboard button, select your Quest from the device picker window pane, and watch the automated sync engine track!
